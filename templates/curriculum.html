Program progression

Git readiness first, then four project phases

The class follows the same learning sequence regardless of which industry project a student selects.

Weeks 1–2 · Required readiness gate

Git, GitHub, VS Code, pull requests, review, and merge conflicts come first.

Students must prove the complete source-control workflow before the classroom begins industry functionality.

Weeks 3–6Understand and design

Discovery, architecture, data modeling, data quality, and access control.

Weeks 7–10Automate and engineer

Flow, Apex services, queries, triggers, secure code, and automated testing.

Weeks 11–13Integrate and build experience

Real external integrations, LWC foundations, files, communication, and performance.

Weeks 14–16Release modern solutions

DevOps, debugging, AI-assisted development, MCP, Agentforce, and final delivery.
