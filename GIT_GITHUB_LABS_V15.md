# Git and GitHub Readiness Labs

## Week 1: Git and GitHub Foundations

1. Secure GitHub identity
2. Install and verify tools
3. Configure Git author data
4. Create Git Foundations Portfolio
5. Learn working tree, staging, commits, and status
6. Practice history and safe undo
7. Create and merge a feature branch
8. Publish to GitHub and pass the readiness check

## Week 2: Classroom GitHub Workflow

1. Clone the classroom repository
2. Understand Salesforce DX source structure
3. Authenticate the training org without committing secrets
4. Create a student feature branch from updated main
5. Commit through VS Code Source Control
6. Push and open a draft pull request
7. Review a peer and address feedback
8. Resolve a controlled conflict, merge, and synchronize main
